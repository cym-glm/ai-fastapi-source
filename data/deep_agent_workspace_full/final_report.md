# AI Agent 平台调研报告
            ## 一、调研目标
            帮我调研一下 AI Agent 平台竞品，并输出一份结构化报告。
            ## 二、资料整理
            模拟搜索结果：
1. Dify：偏应用编排和企业知识库。
2. Coze：偏低门槛 Bot 和工作流搭建。
3. LangGraph：偏开发者 Agent 编排框架。
4. AutoGen：偏多 Agent 协作研究。
5. CrewAI：偏角色化 Agent 团队协作。
            ## 三、分析结论
            分析结论：
1. 低门槛平台更适合业务人员快速搭建。
2. 开发者框架更适合复杂企业系统集成。
3. 企业级 Agent 平台通常需要 RAG、工具调用、权限、日志、评估和部署能力。
4. 趋势是从单点 Chatbot 走向可编排、可观测、可评估的 Agent 平台。
            ## 四、总结
            AI Agent 平台正在从简单问答工具，演进为集成 RAG、工具调用、工作流编排、多 Agent 协作、权限控制、日志观测和评估体系的企业级智能应用平台。
