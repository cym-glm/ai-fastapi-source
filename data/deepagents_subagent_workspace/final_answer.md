本次任务通过 Main Agent 委派多个 Sub-Agent 完成。Research Agent 负责资料收集，Analysis Agent 负责分析，Writer Agent 负责生成草稿，Reviewer Agent 负责审查。主 Agent 不直接处理所有细节，而是负责规划、委派、收集结果和最终整合。
